# System logos

Console logos shown on the Home and Systems pages. They are trademarks of their
owners (Sony Interactive Entertainment, Nintendo, Microsoft, Sega) and are used only to
identify which system a game belongs to; OmniPC is not affiliated with or endorsed by them.

Files come from Wikimedia Commons, where they are marked as below (most are simple text
logos, which Commons lists as public domain but which remain trademarks). They are not
